# 日本の伝統色 TUI

日本の伝統色(和色)をターミナル上でブラウズできる、追加ライブラリ不要のTUI(テキストユーザーインターフェース)ツールです。

厳選した100色を収録し、色名・よみ・ローマ字・HEXコード・分類・簡単な由来を確認できます。

## 特徴

- Python標準ライブラリ(`curses`)のみで動作、追加インストール不要
- 一覧画面で各色をターミナルの背景色として表示(xterm 256色パレットに近似変換)
- 色名・よみ・ローマ字で部分一致検索
- 系統(赤・橙・黄・緑・青・紫・茶・黒白灰)での絞り込み
- 選択した色の詳細(HEX・RGB・由来)を表示

## 必要環境

- Python 3.9 以上
- カラー対応のターミナル(ほとんどのモダンなターミナルで動作します)

追加のパッケージインストールは不要です。

## 実行方法

```bash
python3 colors_tui.py
```

## キー操作

| キー | 動作 |
| --- | --- |
| `↑` / `↓` または `k` / `j` | 選択移動 |
| `←` / `→` | 色の系統(分類)を切り替え |
| `/` | 名前・よみ・ローマ字で検索 |
| `Enter` | 選択中の色の詳細を表示 |
| `Esc` / `q` | 詳細画面を閉じる / 終了 |

## データについて

`data/colors.json` に100色を収録しています。各エントリは以下の形式です。

```json
{
  "name": "藍色",
  "reading": "あいいろ",
  "romaji": "aiiro",
  "hex": "#165E83",
  "family": "blue",
  "note": "藍で染めた、日本の代表的な青。"
}
```

> **注意:** 伝統色は本来、植物染料や顔料など「現物」を基準に伝えられてきた色であり、
> 単一の公式なデジタルHEX値が定められているわけではありません。本データのHEXコードは、
> 一般に広く参照されている資料をもとにした近似値です。学術的・商業的な色再現の
> 厳密な基準としてではなく、鑑賞・学習用の目安としてご利用ください。

## 色を追加・編集する

`data/colors.json` に同じ形式でオブジェクトを追加するだけで反映されます。
`family` は以下のいずれかを想定しています。

`red` / `orange` / `yellow` / `green` / `blue` / `purple` / `brown` / `neutral`
