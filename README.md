# iroquiz — 日本の伝統色クイズ

日本の伝統色の「色名」「特徴」「トリビア」を4択クイズ形式で出題する、
ターミナル上で動作する学習ツール(TUI アプリ)です。

紅・藍・萌黄・山吹色といった伝統色には、名前だけでなく、由来となった
自然物や染料・顔料、歴史や文学にまつわる豆知識があります。iroquiz は
それらを楽しみながら覚えることを目的としています。

## 特徴

- **3種類の出題** — 色見本から色名を当てる／色名から特徴を当てる／
  色名からトリビアを当てる
- **紛らわしい4択** — 誤答は正解と同じ系統(カテゴリ)の色から優先的に
  選ばれ、選択肢の順序は毎回シャッフルされる
- **カテゴリ指定出題** — 赤系・橙系・黄系・緑系・青系・紫系・白黒鼠系の
  7カテゴリから対象を絞って出題
- **苦手優先出題** — 過去の正答率に基づき、苦手な色ほど出題されやすく
  なる重み付き出題
- **一覧表示** — 全36色をカテゴリ順にスクロール表示(色見本・読み・
  カラーコード付き)
- **成績の記録** — 累計の正答数・出題数・正答率、および正答率の低い色を
  確認可能。成績はアプリ終了後も保持される
- **解答後フィードバック** — 正誤にかかわらず、正解の色名・色見本・
  特徴・トリビアをまとめて表示

## 動作環境

- Python 3(標準ライブラリのみ。`curses` を使用)
- Linux のターミナル(80桁×24行程度以上を推奨)

外部ライブラリのインストールは不要です。カラー対応端末では色見本を
実際の色に近い8色で表示し、非対応端末ではカラーコードのテキスト表示に
自動的に切り替わります。

## 使い方

リポジトリのルートで以下を実行します。

```sh
python -m iroquiz
```

### 起動オプション

| オプション | 説明 |
| --- | --- |
| `--state-file PATH` | 成績の保存先ファイル(既定: `~/.iroquiz_stats.json`) |

### 操作

- メインメニュー: 数字キーでモードを選択、`q` で終了
- 出題画面: `1`〜`4` で解答、`s` でスキップ、`q` / `ESC` でメニューへ戻る
- 一覧画面: `↑` / `↓`、`j` / `k`、`PageUp` / `PageDown` でスクロール

## データについて

全36色(赤系6・橙系5・黄系5・緑系6・青系7・紫系4・白黒鼠系3)の
データは `iroquiz/data/colors.json` に格納されています。カラーコードは
染料・顔料が実現する色味の**目安の近似値**であり、厳密な測色値では
ありません。印刷物等の厳密な色再現を保証するものではありません。

## 構成

```
iroquiz/
├── __main__.py   CLI エントリポイント(argparse)
├── data.py       伝統色データのロード(Color データクラス)
├── data/
│   └── colors.json   36色分のデータ本体
├── quiz.py       出題ロジック(4択作成・重み付け抽選・採点)
├── stats.py      成績の永続化(JSON ファイル読み書き)
└── tui.py        curses による画面描画・入力処理
```

ロジック層(`data.py` / `quiz.py` / `stats.py`)は curses に依存せず、
TTY なしで import・単体実行できます。詳細は
[`iroquiz/requirement.md`](iroquiz/requirement.md)(要求仕様)と
[`iroquiz/spec.md`](iroquiz/spec.md)(設計仕様)を参照してください。
